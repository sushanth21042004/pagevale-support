Quick answers

Start here

01

Files will not open

Choose files through the system picker. If a cloud file has a download icon, download it in Files or Finder first, then try again.

02

Find a finished PDF

After a tool completes, choose Save Copy or Save All and select a destination. PageVale never overwrites the original.

03

Restore PageVale Pro

Open the PageVale Pro screen and choose Restore Purchases. Use the same Apple Account that made the purchase.

04

Password-protected files

Use the correct document password and only unlock files you are authorized to access. Document passwords are used on your device, not sent to a PageVale server.

05

Compression results

Results vary with document content. Smaller files can mean lower image quality, and not every target size is achievable. Review the output before sharing.

06

Webpage to PDF

This tool needs an internet connection only to load the address you enter. Other document tools are designed to work locally.

Contact support

Tell us what happened.

Include the PageVale version, your Apple device and OS version, the tool you used, and what you expected. Please do not attach confidential documents or share document passwords.

Support uses GitHub Issues and requires a GitHub account. Requests and replies are public. Share only non-sensitive details.

Before sending

  • Install the latest PageVale update.
  • Try a non-confidential sample file.
  • Confirm sufficient free storage is available.
  • Remove personal information from screenshots.
